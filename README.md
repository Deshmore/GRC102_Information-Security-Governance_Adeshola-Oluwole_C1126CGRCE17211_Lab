# GRC102_Information-Security-Governance_Adeshola-Oluwole_C1126CGRCE17211_Lab
GRC 102 Lab Assignment on Information Security Governance

1. Laboratory Overview
You have been appointed Director of Information Security Governance at GlobalHealth Connect (GHC), a mid-sized health-technology organisation that provides cloud-based patient management systems. Following rapid growth, two acquisitions and a contained data-leakage near-miss, the Board has determined that GHC's current ad-hoc security approach is no longer sustainable.
This practical laboratory places you inside a realistic governance environment. Rather than performing technical command-line tasks, you will analyse organisational information, respond to executive requests, design governance artefacts, interpret security metrics and build a practical roadmap that turns a reactive security programme into a business-aligned governance function.

2. Learning Objectives
• Design an information security governance structure appropriate to a growing organisation.
• Define accountability using organisational structures and a RACI responsibility model.
• Draft a formal Information Security Charter that establishes mandate, authority and scope.
• Translate technical security information into concise Board-level metrics and risk reporting.
• Design a Security Steering Committee that supports cross-functional decision-making.
• Assess governance maturity and propose a measurable 12–18 month improvement roadmap
